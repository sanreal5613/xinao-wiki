## 竞赛体系

```
CSP-J（入门组）
    ↓
CSP-S（提高组）
    ↓
NOIP（省级联赛）
    ↓
省选 → NOI（全国赛）
    ↓
国家集训队 → IOI（国际赛）
```

---

## 各阶段要求

### CSP-J（入门组）

**适合**：初学者，小学高年级至初中

**考察内容**：
- C++ 基础语法
- 简单算法（排序、搜索、贪心）
- 基础数据结构（数组、字符串）

**分数线**：一般 50-70 分可获奖

### CSP-S（提高组）

**适合**：有一定基础，初中至高中

**考察内容**：
- 进阶算法（DP、图论）
- 高级数据结构（树、图、线段树）
- 数学基础（数论、组合）

**分数线**：一般 100-150 分可获奖

### NOIP

**适合**：CSP-S 成绩优秀者

**难度**：与 CSP-S 相当或略高

## 备考建议

### 长期规划（6-12 个月）

| 阶段 | 时间 | 任务 |
|------|------|------|
| 基础阶段 | 1-2 月 | C++ 语法、简单算法 |
| 提高阶段 | 2-3 月 | 数据结构、基础 DP |
| 强化阶段 | 2-3 月 | 图论、高级 DP |
| 冲刺阶段 | 1-2 月 | 模拟赛、查漏补缺 |

### 每日练习

- **刷题量**：每天至少 3-5 题
- **难度分布**：简单:中等:困难 = 3:5:2
- **时间管理**：每题控制在 30-60 分钟

## 应试技巧

### 赛前准备

1. **熟悉环境**：提前了解比赛系统、编译器版本
2. **准备模板**：整理常用代码模板
3. **调整作息**：保证充足睡眠
4. **心理调节**：保持平常心，不要紧张

### 赛中策略

#### 时间分配（4 小时比赛）

| 阶段 | 时间 | 任务 |
|------|------|------|
| 读题 | 10-15 分钟 | 通读所有题目，评估难度 |
| 第一题 | 30-45 分钟 | 先做最简单的 |
| 第二题 | 45-60 分钟 | 中等难度 |
| 第三题 | 60-90 分钟 | 最难的 |
| 检查 | 30 分钟 | 测试、检查边界 |

#### 做题顺序

1. **先易后难**：快速拿下简单题，建立信心
2. **部分得分**：不会正解也要写暴力，拿部分分
3. **及时放弃**：卡太久先跳过，做其他题
4. **最后检查**：检查文件名、输入输出格式

### 代码规范

```cpp
// 1. 清晰的变量命名
int n, m;           // 数据规模
vector<int> a;      // 数组
int ans;            // 答案

// 2. 必要的注释
// 读入数据
for (int i = 0; i < n; i++) {
    cin >> a[i];
}

// 3. 模块化设计
void solve() {
    // 主逻辑
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int T = 1;
    // cin >> T;  // 多组数据
    while (T--) {
        solve();
    }
    
    return 0;
}
```

## 常见失误

| 失误 | 后果 | 预防 |
|------|------|------|
| 数组越界 | RE（运行时错误） | 数组开够大 |
| 整数溢出 | WA（答案错误） | 用 long long |
| 忘记初始化 | WA | 养成初始化习惯 |
| 文件名错误 | 0 分 | 仔细核对 |
| 输出格式错 | WA | 对照样例 |
| 死循环 | TLE（超时） | 检查循环条件 |

---

## 赛后总结

1. **复盘**：分析错题原因
2. **补题**：把比赛中没做出的题补完
3. **整理**：归纳新学的算法和技巧
4. **调整**：根据表现调整学习计划
