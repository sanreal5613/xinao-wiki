# 数据结构

数据结构是组织和存储数据的方式，选择合适的数据结构可以大大提高算法效率。

---

## 为什么学数据结构？

> "算法 + 数据结构 = 程序"

不同的数据结构适用于不同的场景：

| 数据结构 | 特点 | 适用场景 |
|---------|------|---------|
| 数组 | 随机访问 O(1) | 数据量固定，频繁查询 |
| 链表 | 插入删除 O(1) | 频繁增删，不频繁查询 |
| 栈 | 后进先出 | 括号匹配、表达式求值 |
| 队列 | 先进先出 | BFS、任务调度 |
| 树 | 层次结构 | 搜索、排序、表达式 |
| 图 | 网络结构 | 最短路径、网络流 |

## 复杂度对比

| 操作 | 数组 | 链表 | 栈 | 队列 | 二叉搜索树 |
|------|------|------|-----|------|-----------|
| 访问 | O(1) | O(n) | O(n) | O(n) | O(log n) |
| 插入 | O(n) | O(1) | O(1) | O(1) | O(log n) |
| 删除 | O(n) | O(1) | O(1) | O(1) | O(log n) |
| 搜索 | O(n) | O(n) | O(n) | O(n) | O(log n) |

## STL 容器速查

```cpp
#include <bits/stdc++.h>
using namespace std;

// 数组替代品
vector<int> v;          // 动态数组
array<int, 5> arr;      // 固定大小数组（C++11）

// 栈和队列
stack<int> stk;         // 栈
queue<int> q;           // 队列
priority_queue<int> pq; // 优先队列（大根堆）

deque<int> dq;          // 双端队列

// 集合
set<int> s;             // 有序集合
unordered_set<int> us;  // 哈希集合（C++11）

// 映射
map<int, int> mp;               // 有序映射
unordered_map<int, int> ump;    // 哈希映射（C++11）

// 链表
list<int> lst;          // 双向链表
forward_list<int> fl;   // 单向链表（C++11）
```

## 选择指南

| 需求 | 推荐容器 |
|------|---------|
| 频繁随机访问 | `vector`, `array` |
| 频繁头尾插入删除 | `deque` |
| 频繁中间插入删除 | `list` |
| 需要排序 | `set`, `map` |
| 快速查找 | `unordered_set`, `unordered_map` |
| 取最大/最小 | `priority_queue` |

## 学习建议

1. **先理解原理**：不要只会调用 STL
2. **能手写实现**：比赛时可能需要自定义
3. **多做练习**：每个数据结构至少做 5 道题
4. **对比分析**：理解不同数据结构的优劣
