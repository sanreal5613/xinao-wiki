# 动态规划

动态规划（Dynamic Programming，简称 DP）是解决多阶段决策最优化问题的有效方法。

---

## 什么是动态规划？

**核心思想**：将大问题分解为子问题，保存子问题的解，避免重复计算。

**适用条件**：
1. **最优子结构**：问题的最优解包含子问题的最优解
2. **无后效性**：当前状态只与前面状态有关，与后面无关
3. **重叠子问题**：子问题会被重复计算

---

## 经典例子：斐波那契数列

### 递归（低效）

```cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // 大量重复计算
}
// 时间复杂度：O(2^n)
```

### 记忆化搜索

```cpp
int dp[100];

int fib(int n) {
    if (n <= 1) return n;
    if (dp[n] != 0) return dp[n];  // 已经计算过
    return dp[n] = fib(n-1) + fib(n-2);
}
// 时间复杂度：O(n)
```

### 递推（DP）

```cpp
int fib(int n) {
    int dp[100];
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}
// 时间复杂度：O(n)，空间复杂度：O(n)
```

### 空间优化

```cpp
int fib(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}
// 时间复杂度：O(n)，空间复杂度：O(1)
```

## DP 解题步骤

```
1. 定义状态
   └── 确定 dp[i] 或 dp[i][j] 的含义
   
2. 状态转移方程
   └── 找出状态之间的关系
   
3. 初始化
   └── 确定边界条件
   
4. 计算顺序
   └── 确定遍历顺序（从小到大或从大到小）
   
5. 返回结果
   └── 通常是 dp[n] 或 dp[n][m]
```

## DP 分类

### 按维度分

| 类型 | 状态定义 | 例子 |
|------|---------|------|
| 一维 DP | dp[i] | 斐波那契、爬楼梯 |
| 二维 DP | dp[i][j] | 背包、最长公共子序列 |
| 多维 DP | dp[i][j][k] | 复杂状态问题 |

### 按模型分

| 模型 | 特点 | 例子 |
|------|------|------|
| 线性 DP | 状态按线性排列 | 最长上升子序列 |
| 背包 DP | 资源限制问题 | 01 背包、完全背包 |
| 区间 DP | 区间合并问题 | 石子合并 |
| 树形 DP | 树上的 DP | 树的最大独立集 |
| 状压 DP | 状态压缩 | 旅行商问题 |
| 数位 DP | 数字位运算 | 计数问题 |

## DP 优化技巧

### 1. 滚动数组

```cpp
// 二维 DP 优化为一维
// 原：dp[i][j] = max(dp[i-1][j], dp[i-1][j-w] + v)
// 优化后：
for (int i = 1; i <= n; i++) {
    for (int j = W; j >= w[i]; j--) {  // 注意倒序
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
```

## 学习建议

1. **从简单开始**：先掌握线性 DP 和背包
2. **理解状态定义**：这是最关键的一步
3. **画表格**：手动推导 DP 表格帮助理解
4. **多做题**：每种类型至少做 10 道
5. **总结模型**：归纳常见 DP 模型
