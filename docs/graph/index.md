# 图论

图论是研究图（由顶点和边组成的结构）的数学分支，在信息学竞赛中占有重要地位。

---

## 什么是图？

**图（Graph）** 由顶点（Vertex）和边（Edge）组成：

```
    1 ---- 2
    |      |
    |      |
    3 ---- 4
    
顶点：1, 2, 3, 4
边：(1,2), (1,3), (2,4), (3,4)
```

---

## 图的分类

### 按边是否有方向

| 类型 | 说明 | 例子 |
|------|------|------|
| 无向图 | 边没有方向 | 社交网络好友关系 |
| 有向图 | 边有方向 | 网页链接关系 |

### 按边是否有权重

| 类型 | 说明 | 例子 |
|------|------|------|
| 无权图 | 边没有权重 | 简单连接关系 |
| 带权图 | 边有权重 | 地图距离、网络带宽 |

### 按是否有环

| 类型 | 说明 | 例子 |
|------|------|------|
| 有环图 | 存在环路 | 大多数图 |
| 无环图（DAG） | 没有环路 | 任务依赖关系 |
| 树 | 连通无环图 | 文件系统 |

## 图的存储方式

### 邻接矩阵

```cpp
const int MAXN = 1005;
int g[MAXN][MAXN];  // g[i][j] 表示 i 到 j 的边权

// 初始化
memset(g, 0x3f, sizeof(g));  // 初始化为无穷大
for (int i = 1; i <= n; i++) g[i][i] = 0;

// 添加边
g[u][v] = w;  // 有向图
g[u][v] = g[v][u] = w;  // 无向图
```

**优点**：查询两点间是否有边 O(1)
**缺点**：空间 O(n²)，稀疏图浪费空间

### 邻接表

```cpp
const int MAXN = 1005;
const int MAXM = 10005;

// 链式前向星
int head[MAXN], nxt[MAXM], to[MAXM], w[MAXM];
int cnt = 0;

void addEdge(int u, int v, int weight) {
    to[++cnt] = v;
    w[cnt] = weight;
    nxt[cnt] = head[u];
    head[u] = cnt;
}

// 遍历 u 的所有邻接点
for (int i = head[u]; i; i = nxt[i]) {
    int v = to[i];
    int weight = w[i];
    // 处理边 (u, v)
}
```

**优点**：空间 O(n+m)，适合稀疏图
**缺点**：查询两点间是否有边需要遍历

### STL 实现

```cpp
vector<pair<int, int>> g[MAXN];  // g[u] = {(v, w), ...}

// 添加边
g[u].push_back({v, w});

// 遍历
for (auto& [v, w] : g[u]) {
    // 处理边 (u, v, w)
}
```

## 图论算法概览

| 问题 | 算法 | 时间复杂度 | 适用场景 |
|------|------|-----------|---------|
| 单源最短路 | Dijkstra | O((n+m)log n) | 非负权图 |
| 单源最短路 | SPFA | O(km) ~ O(nm) | 有负权边 |
| 多源最短路 | Floyd | O(n³) | 多源、可处理负权 |
| 最小生成树 | Prim | O((n+m)log n) | 稠密图 |
| 最小生成树 | Kruskal | O(m log m) | 稀疏图 |
| 拓扑排序 | Kahn/BFS | O(n+m) | DAG |
| 连通分量 | DFS/BFS/并查集 | O(n+m) | 无向图 |

4. **多做题**：图论题目类型多，需要大量练习
